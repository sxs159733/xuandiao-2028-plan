# 选调计划 · 2028 届（湖南优先）

「考公选调」行动计划与信息跟踪的静态站点。以湖南省定向选调为第一优先、广东省定向选调为第二优先，完整保留计划中的主题、目标、步骤、重点信息与关键术语，按清晰的信息层级组织，并补充必要的说明、概括与视觉化呈现。

> **内容政策**：本仓库所有内容来自以下两份既有文档，未添加计划之外的事实。所有 2027 届批次仅作观察样本，不构成报名建议；所有 2028 届日期均为按历年规律推算值，具体条款与时间以当年官方公告为准。

| 来源 | 位置 | 作用 |

| `选调与国考信息整理_湖南优先.html` | 工作区根目录（2026-11-10 第 15 轮） | 计划执行成果：13 省通道清单、四条主赛道、奖学金口径四型、时间轴、行动清单、官方入口与 footer 数据口径 |

数据基准：**2026-11-10（GMT+8）**。届别基准：**2028 届**。

## 设计与适配

- 深色主题沿用主报告的 CSS 变量色板；红 = 硬缺口与时间风险，绿 = 已合格，琥珀 = 需注意，蓝 = 中性说明。
- 顶部常驻导航，桌面横向排列、移动端可横向滚动；桌面多列网格在窄屏自动折叠为单列；表格统一放进横向滚动容器。
- 无外部字体、图片、CDN 或构建步骤；HTML / CSS / JS 全部本地化，离线可直接打开。
- 视觉化呈现：检索优先级阶梯、备考配比条形、倒计时卡片、SOP 步骤流、11 节报告地图、时间轴、状态徽章、色板示意。条形长度只表示顺序或相对权重，不代表名额或成功率。

## 本地预览

```bash

python -m http.server 8000
# 打开 http://localhost:8000/
```

也可以直接双击 `index.html`（站内链接为相对路径，均可正常跳转）。

## 发布

本仓库以 GitHub Pages 发布，发布源为默认分支根目录，入口为 `index.html`。站内所有链接均为相对路径，官方信源链接为绝对 HTTPS 地址并在新标签打开。
