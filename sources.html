03

检索方法与冲突处理

检索方法

第 6.2 节
  • 广撒网：关键词组合「省份 + 年度 + 定向选调 + 公告 / 湖南大学」。
  • 命中后必须抓官方公告原文核对，机构转载只作线索。
  • 官方附件下载后逐条匹配校名 / 专业代码 / 省份——第 11 轮就是靠这条链路证实「江苏附件 1 无湖大、附件 2 有湖大、附件 4 按类别不按校」。
  • 职位表 / 高校名单类数据，宁可下载原件逐条匹配，不要引用机构摘要里的结论。
  • 每轮并行查省级组织部 / 人社厅官网 + 湖大通知公告 + 招聘日历 + 多校就业网，并逐条翻湖大历史页，防两类漏检。

数据冲突处理

第 6.3 节

同一指标出现两个值时，用能自洽的一组并在报告里写明剔除原因。

  • 广东首日「46,242 人 / 10,293 计划」→ 竞争比应约 4.5—4.8:1，故采信 4.81:1，剔除 14.81:1。
  • 历史同类：国考「302.5 万 / 85:1」被终审「345 万过审 / 97:1」替代。
  • 11/6 9:00 只发冷热岗（376 / 262），机构表格把 200,653 沿用列在「第三日报名人数」列，不采用为 11/6 新全量值。

验收：怎么判断执行成功

计划第 15 节。以下六条用于每轮自检，也用来校验本站点是否完整保留了计划。

  • 存在一个每天 05:05（GMT+8）触发、状态 ACTIVE 的循环任务，任务名「考公选调」。
  • 生成 / 更新了主报告 HTML，00 节标题日期是执行当天。
  • .bak.html 是执行前那一版。
  • 跨轮 memory.md 末尾多了一条「执行记录」，当日日志已创建。
  • 回复正文是短行、结论前置、无宽表格的 5—8 条要点，并给出了 HTML 路径。
  • 若广东 2027 选调公告仍未发布，正文或报告里明确写「截至 YYYY-MM-DD 仍未发布」而不是略过。
