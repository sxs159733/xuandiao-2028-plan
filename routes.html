四条主赛道横向对比

平台 / 名额、门槛、定位三项对照。其他省份定向与湖南省考、国考的定位索引在本页第 02 节展开。

湖南定向选调

第一优先

平台 / 名额：A 类省直 / B 类市州直 / 常规 600 人；2027 届总计划 1,000 人，实到 988。
门槛：A 类党员硬线；B 类 / 常规「党员或主要学生干部满 1 学年」二选一。
定位：第一优先，衡阳名额多、完整周期 6 个月。

广东选调

冲平台（主）

平台 / 名额：2026 年度 1,715 人，全在省直 / 市直 / 县直；Ⅰ 类高校可报所有岗位。
门槛：四选一，双奖学金命中；成绩前 50% 只约束 Ⅱ / Ⅲ 类本科生。
定位：冲平台（主）。

广东省考

保底（辅）

平台 / 名额：2027 年度 10,293 人 / 8,211 职位；实测可报 490 职位 / 773 人，63% 在乡镇。
门槛：零软条件，用户已完整满足。
定位：保底（辅）；研究生 + 珠三角 + 县以上黄金池仅 31 职位 / 33 人。

国考

补充

平台 / 名额：2027 年度 35,691 人 / 19,426 职位；湖南地区 1,174 人 / 584 职位。
门槛：无软条件，但过审与计划比约 97:1。
定位：补充；11-29 笔试与 12-06 省考只隔 7 天。

结论层的排序 广东「选调冲平台（主）+ 省考保底（辅）」；湖南线优先 B 类 / 常规。此前「广东省考是主力」已作废，理由见总览页第 05 节。

03

奖学金口径四型

第 15 轮把 13 省逐条读原文后归纳的机制。此前「双奖学金命中第 3 条」是 B 型结论，A / C / D 三型不能直接外推。

A 型 · 明确排除

天津

「四选一」第 3 条为校级及以上荣誉称号，原文括注「不包含各类奖学金」。用户双奖学金不能替代党员；按现行条款不可报。

B 型 · 认可且无阶段限定

6 条通道

广东、广西、青海、重庆、贵州、湖南 B 类与常规。「四选一 / 五选一 / 三选一」中的「校级以上奖学金或表彰」，用户国家励志奖学金 + 校级一等奖学金双命中。

C 型 · 仅作同等条件下优先

新疆

党员、荣誉、奖学金、干部、参军只列为「同等条件下可优先选调」，不是报名门槛。用户校级一等奖学金命中「校级二等及以上奖学金」的表述，但资格来自零软条件。

D 型 · 认可但限定阶段

江西

「4 项条件之一」第 ③ 条要求「最高学历期间」获校级及以上荣誉称号，或获校级二等及以上奖学金。等级命中，但取得阶段待确认 → 判条件型，不虚增确定性可报。

固定 4 列核查表（第 15 轮固化） 2028 届逐省核查表须列：① 是否排除奖学金 ② 是门槛还是仅优先 ③ 是否限定最高学历期间 ④ 是否限定奖学金等级。天津明确排除、新疆仅作优先、江西限定阶段，机构汇总常把三者写反，别再依赖机构表格。

05

数据冲突怎么处理

同一指标出现两个值时，用能自洽的一组，并在报告里写明剔除原因。这是计划第 6.3 节与「口径纠错原则」的共同要求。

采用 4.81:1 / 19.49:1

自洽

广东首日 46,242 人 ÷ 10,293 计划 ≈ 4.49—4.8:1，故采信 4.81:1；全量终值 200,653 人 / 19.49:1（11/4 18:00），时间序列 46,242 → 93,165 → 114,349 → 200,653 各值均可由「报名人数 ÷ 10,293」校验。

不采用 14.81:1 / 302.5 万

不自洽 / 已替代

「14.81:1」与 46,242÷10,293 不自洽，不采用；国考「302.5 万 / 85:1」已被终审 393.5 万报名 / 345 万过审 / 约 97:1 替代。11/6 9:00 只发冷热岗（376 岗高于 1:200 / 262 岗低于 1:5），不是全量新值。

信源分级 只采信官方公告原文；机构数据须标注来源与非官方性质。职位表 / 高校名单类数据，宁可下载原件逐条匹配，不引用机构摘要里的结论。广东省考「11/6 9:00 为最后一次发布且只发冷热岗」第 15 轮已由官方公告原文直接证实，从推断升级为证据。
